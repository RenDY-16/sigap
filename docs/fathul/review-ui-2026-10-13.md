Arahan pengguna: magazine UI + minimalism di seluruh aplikasi, putih terang, aset berbeda sesuai topik. Hero kota landing yang dipilih dipertahankan.

## Urutan koreksi

1. Dashboard staff: header operasional ringkas dan antrean lebih dekat ke atas.
2. Pelapor: copy sederhana dan status tanpa pengulangan.
3. Landing: section alur lebih pendek dengan alignment konsisten.
4. Halaman staff pendamping: pola judul/toolbar bersama.
5. Periksa render desktop dan mobile setelah perubahan. Build saja bukan bukti visual.

Review tidak mengubah produk. Jangan mengubah authorization, draft/idempotency, GPS, scope wilayah, status stale, simulasi atau batas layanan resmi selama koreksi visual.
